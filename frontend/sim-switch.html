Adding recipients means real notifications will fire. Only add internal test users. This is separate from threshold copying.

Recipients are managed via the platform UI — navigate to the mock account's Alert Settings and add users per alert type there.

Tracker Attach Time
tracker_attach_time gates incoming packets: older packets are silently dropped. Attaching a device stamps the current time, so mock vehicles reject replayed historical data unless the attach time is back-dated. This cannot be set via HTTP — use the pod script shown below.
Default: 2026-01-01 00:00 UTC = 1767225600000 ms. Must be 13 digits (ms, not seconds).
